OPB PWA IMPLEMENTATION (WORDPRESS-NATIVE)

Repository Context

This repository contains OPB (Onukonu Pet Boarding), a mature production boarding operations platform implemented as a WordPress plugin.

OPB already includes:

- Clients
- Pets
- Bookings
- Kennels
- Occupancy Board
- Occupancy Timeline
- Tasks
- Invoices
- Payments
- PDF Invoice Engine (mPDF)
- Public Inquiry Intake
- Public Onboarding
- Document Uploads
- Terms Acceptance
- Customization Module
- WhatsApp Delivery
- Email Delivery
- Portal Login

The application is stable and production-used.

--------------------------------------------------
IMPORTANT ARCHITECTURAL DECISION
--------------------------------------------------

OPB intentionally remains inside WordPress.

This is deliberate.

We want to retain:

- WordPress authentication
- WordPress roles and capabilities
- Loginizer integration
- Password reset workflow
- User management
- Auditability
- Security plugins
- SMTP plugins
- WooCommerce interoperability
- Future notification framework interoperability

DO NOT:

- Move OPB outside WordPress
- Create a separate frontend application
- Create a separate authentication system
- Replace WordPress users
- Rewrite the portal architecture

--------------------------------------------------
STEP 1 – INSTALLABILITY AUDIT
--------------------------------------------------

Determine exactly why Chrome Android does not offer installation.

Audit:

- Manifest injection
- Manifest validity
- Manifest location
- Service worker registration
- Service worker scope
- Start URL
- Scope
- Icons
- Theme color
- Install prompt logic
- beforeinstallprompt handling

Provide a browser-level root cause analysis.

--------------------------------------------------
STEP 2 – REVIEW CURRENT IMPLEMENTATION
--------------------------------------------------

Inspect:

- portal implementation
- React bootstrap
- WordPress hooks
- admin page rendering
- manifest generation
- service worker generation
- existing PWA code

Determine:

1. What currently exists?
2. What is incomplete?
3. What is invalid?
4. What prevents installation?

--------------------------------------------------

SERVICE WORKER

- OPB static assets
- CSS
- JS bundles

- bookings
- invoices
- kennel data
- onboarding data
- client records
