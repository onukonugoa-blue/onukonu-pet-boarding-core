PWA INSTALLABILITY FIX – HOSTINGER COMPATIBILITY RELEASE

Repository Context

This repository contains OPB (Onukonu Pet Boarding), a production WordPress-based operational platform.

Portal login is functioning.

Invoice engine is functioning.

PDF generation is functioning.

Customization system is functioning.

The remaining issue is PWA installability.

A browser-level audit has already been completed.

Do not re-investigate from scratch.

Use the findings below.

---

ROOT CAUSE (CONFIRMED)

Current PWA URLs:

/opb-manifest.json
/opb-sw.js

Both return HTTP 404 on the live Hostinger server.

Chrome therefore cannot:

- load the manifest
- register the service worker
- reach installable state
- fire beforeinstallprompt

The React install logic is NOT the problem.

The browser never reaches installability.

---

WHY THIS HAPPENS

Hostinger's Apache configuration intercepts requests ending in:

.json
.js

before they reach WordPress.

Therefore:

/opb-manifest.json
/opb-sw.js

never execute the WordPress handlers.

The rewrite rules are present.

WordPress code is present.

The requests simply never reach WordPress.

---

CONFIRMED WORKING ENDPOINTS

These URLs successfully reach WordPress:

/?opb_manifest=1
/?opb_sw=1

Verified on production:

Manifest:

HTTP 200
Content-Type: application/manifest+json

Service Worker:

HTTP 200
Content-Type: application/javascript
Service-Worker-Allowed header present

The generated manifest is valid.

The generated service worker is valid.
