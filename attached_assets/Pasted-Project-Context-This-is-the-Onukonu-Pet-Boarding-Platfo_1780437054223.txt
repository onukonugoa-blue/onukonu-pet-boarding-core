## OBJECTIVE

Implement a clean operational kennel management experience.

This is NOT a hotel management system.

This is NOT a forecasting engine.

This is NOT a scheduling platform.

This is a boarding facility operations tool.

Primary operational questions:

1. Which kennel is this pet occupying?
2. Which kennels are free?
3. Which kennels are unavailable?
4. Which staff member is responsible for a kennel?
5. Which kennels become available over the next few days?
